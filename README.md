# GestureAI — Pose Dataset Pipeline

Dataset generation pipeline for **GestureAI**, a pedagogical tool for learning to draw the human body.

For each selected pose, the pipeline produces two outputs:
- **Pedagogical view** — Blender render (EEVEE/Cycles) with Bridgman geometric overlay and anatomical view
- **Photo-realistic view** — image generated by Flux.1 Schnell from the depth map

## Installation

### Prerequisites

- Python 3.10+
- UV (`pip install uv`)
- Blender 4.0 installed and available in PATH (`blender --version`)
- CUDA 13 recommended for PyTorch

### Clone with submodules

```bash
git clone --recurse-submodules <repo-url>
cd gestureai-pose-pipeline
```

If already cloned without submodules:

```bash
git submodule update --init
```

### CMU Mocap sparse checkout (used subjects only)

```bash
cd data/cmu
git sparse-checkout set data/005 data/013 data/014 data/015 data/060 data/061 data/062 data/063 data/064
git checkout
cd ../..
```

### Blender addon — retarget_bvh

Install the `retarget_bvh` addon in Blender 4.0:

```
~/.config/blender/4.0/scripts/addons/retarget_bvh-master/
```

### Install Python environment

```bash
uv sync
```

NAVER Labs parametric body model. Installed as a UV editable workspace.

## Pipeline architecture

```
CMU Mocap BVH
    ↓
[1] BVH parsing → joint rotations (bvh_reader.py ✓)
    ↓
[2] Frame selection (pose diversity)
    ↓
[3a] Pure Python retargeting (retarget.py) — T-pose ✓, animation ⚠ in progress
  OR
[3b] Headless Blender retargeting (blender_retarget.py) — ✓ working
    ↓
[4] Mesh export → headless Blender (to implement)
    → depth map | anatomical view | Bridgman overlay
    ↓
[5] Flux.1 Schnell ControlNet Depth → photo-realistic output (to implement)
```

## Commands

```bash
# Validate T-pose (BVH frame 0 ↔ calibrated Anny)
uv run python src/validate_tpose.py
uv run python src/validate_tpose.py --bvh data/cmu/data/013/13_01.bvh

# Visualize an animated frame (Python retargeting)
uv run python src/visualize.py --bvh data/cmu/data/005/05_01.bvh --frame 100

# Animated GIF BVH vs Anny (Python retargeting)
uv run python src/animate_bvh.py --bvh data/cmu/data/005/05_01.bvh --start 0 --end 90 --step 3 --fps 12

# Generate retarget JSON via Blender (~30s, cached)
blender --background blender/anny_armature.blend \
        --python blender/retarget_export.py \
        -- data/cmu/data/005/05_01.bvh output/retarget_cache/05_01.json 0 599 1

# Visualize a frame via Blender retarget (with JSON cache)
uv run python src/blender_retarget.py \
    --bvh data/cmu/data/005/05_01.bvh \
    --json output/retarget_cache/05_01.json \
    --frame 100

# Animated GIF via Blender retarget
uv run python src/blender_retarget.py \
    --bvh data/cmu/data/005/05_01.bvh \
    --json output/retarget_cache/05_01.json \
    --gif --gif-frames 60 --fps 12

# Interactive Streamlit 3D explorer
uv run streamlit run src/app.py
```
